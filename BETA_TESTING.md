# 🧪 Programa Beta Testing - Vida Nova

## 🎯 Objetivo
Colocar o app em testes com 30-50 mulheres antes do lançamento oficial para:
- ✅ Encontrar bugs
- ✅ Coletar feedback
- ✅ Melhorar interface
- ✅ Validar negócio (quantas pagariam?)
- ✅ Criar primeiros case studies

---

## 📅 Cronograma (4 Semanas)

```
SEMANA 1: Setup + Recrutamento (Days 1-7)
SEMANA 2: Testes Iniciais (Days 8-14)
SEMANA 3: Coleta Feedback (Days 15-21)
SEMANA 4: Ajustes + Lançamento (Days 22-28)
```

---

```markdown
# 🎉 Bem-vinda ao Beta Testing Vida Nova!

Obrigada por testar nosso app! 💜

## Como Acessar

1. Abra em seu navegador:
   https://vida-nova.onrender.com

   - Nome completo

- Clique em "Agenda"

### ✅ Finanças

- Clique "+"

### ✅ Rotina
- Clique em "Rotina"

- Clique em "Espiritualidade"
- Escreva uma reflexão

- Acesse pelo celular também
- Veja se funciona

### ✅ Offline
- Use o app normalmente
- Desative WiFi/dados
- Continue usando
- Ligar WiFi de novo
- Veja se sincroniza

Quando encontrar problema ou ter ideia:

**Envie para: seu@email.com**

Com:
1. O que aconteceu
```

## 📊 SEMANA 2: Testes Iniciais (7 dias)

### Ações Diárias
- ☐ Conferir formulários Google Form
- ☐ Anotar bugs em BETA_TRACKING.txt
- ☐ Responder dúvidas dos testers
- ☐ CORREÇÃO DE BUGS CRÍTICOS (se necessário)

### Bugs a Procurar
- Erro ao fazer login
- Dados não salvam
- Botões não funcionam
- Erro offline/online
- Problemas mobile

### Se Encontrar Bug Crítico

**Corrija rápido:**

1. Edite arquivo (ex: `script.js`)
2. Teste localmente (`npm start`)
3. Faça `git commit` e `git push`
4. Render faz deploy automático (5 min)
5. Avise testers: "Bug corrigido! Refresque a página"
